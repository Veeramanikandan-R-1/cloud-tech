## **Volume in Kubernetes**

**What is a Volume?**

A Volume provides storage to containers running inside a Pod.

### **Why do we need it?**

- **Data Persistence:** Prevents data loss when containers restart or are replaced (depending on volume type).
- **Data Sharing:** Allows multiple containers in a Pod to share data.
- **External Storage:** Connects Pods to external storage systems.

### **Example**

A Spring Boot application uploads files. Volumes help store uploaded files outside the container filesystem so they can survive container replacement.

### **Types of Volumes**

| Type         | Purpose                                               |
| ------------ | ----------------------------------------------------- |
| emptyDir     | Temporary storage shared between containers in a Pod. |
| hostPath     | Uses storage from the Worker Node.                    |
| PV           | Represents storage available in the cluster.          |
| PVC          | Requests storage for an application.                  |
| StorageClass | Enables dynamic storage provisioning.                 |

**In simple words:** Volumes provide storage to Pods and help preserve application data beyond the lifecycle of a container.
