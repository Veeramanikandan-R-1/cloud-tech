## **1. What is Kubernetes?**

**Kubernetes (K8s)** is an open-source container orchestration platform used to **deploy, manage, scale, and monitor containerized applications**.

### **Why do we need it?**

Suppose you have a Spring Boot application running inside a Docker container.

- What happens if the container crashes?
- How do you run multiple instances?
- How do you distribute incoming traffic?
- How do you scale when users increase?

Kubernetes handles these tasks automatically.

### **Key features**

1. **Container Management:** Manages Docker containers.
2. **Auto Scaling:** Increases or decreases application instances based on demand.
3. **Self-Healing:** Restarts failed containers automatically.
4. **Load Balancing:** Distributes traffic across application instances.
5. **Rolling Updates:** Updates applications without significant downtime.

### **Example**

You have a Spring Boot application:

- Docker packages your application into a container.
- Kubernetes manages multiple running instances of that container.
- If one instance crashes, Kubernetes creates a replacement.

### **Important terms**

- **Cluster:** A group of machines managed by Kubernetes.
- **Node:** A machine inside a cluster.
- **Pod:** The smallest deployable unit in Kubernetes; contains one or more containers.
- **Deployment:** Manages application replicas and updates.
- **Service:** Exposes Pods and distributes traffic between them.

**In simple words:**

- Docker = Packages and runs applications in containers.
- Kubernetes = Manages containers across multiple machines.

**Interview answer:** Kubernetes is a container orchestration platform that automates deployment, scaling, load balancing, and management of containerized applications.

---

### **Why do we need an orchestration tool?**

When applications run in multiple containers, managing them manually becomes difficult.

An orchestration tool like Kubernetes automates:

1. **Deployment:** Deploys containers automatically.
2. **Scaling:** Increases or decreases container instances based on traffic.
3. **Self-Healing:** Restarts failed containers.
4. **Load Balancing:** Distributes traffic across containers.
5. **Networking:** Enables communication between containers.
6. **Updates:** Updates applications with minimal downtime.

**In simple words:** Container orchestration tools automate the management of multiple containers, reducing manual effort and improving application availability and scalability.

---

Kubernetes is called **K8s** because it is an abbreviation.

- **K** – First letter of Kubernetes.
- **8** – Number of letters between K and S.
- **S** – Last letter of Kubernetes.

So, K + 8 letters + S = **K8s**.

This abbreviation is called a **numeronym**.
