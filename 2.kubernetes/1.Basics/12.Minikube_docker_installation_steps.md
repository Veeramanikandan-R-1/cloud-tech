# **Install Minikube on Windows and Run with Docker**

## **1. Prerequisites**

You need the following:

| Tool           | Purpose                                               |
| -------------- | ----------------------------------------------------- |
| Docker Desktop | Runs containers and provides a container environment. |
| Minikube       | Creates a local Kubernetes cluster.                   |
| kubectl        | Communicates with and manages the Kubernetes cluster. |

**Important:** Install and start Docker Desktop before starting Minikube. Make sure Docker Desktop is using Linux containers.

## **2. Install Minikube on Windows**

**Step 1: Install Docker Desktop**

Download and install:

[https://www.docker.com/products/docker-desktop/](https://www.docker.com/products/docker-desktop/?utm_source=chatgpt.com)

- Enable the WSL 2 backend if prompted.
- Start Docker Desktop.
- Wait until Docker Engine is running.

Verify installation:

```
docker --version
docker ps
```

**Step 2: Install kubectl**

Open PowerShell and run:

```
winget install -e --id Kubernetes.kubectl
```

Verify:

```
kubectl version --client
```

**Step 3: Install Minikube**

Run:

```
winget install -e --id Kubernetes.minikube
```

Verify:

```
minikube version
```

**Step 4: Start Minikube using Docker**

```
minikube start --driver=docker
```

This creates a local Kubernetes cluster using Docker as its driver.

**Step 5: Verify the cluster**

```
minikube status
kubectl get nodes
kubectl get pods -A
```

You should see your Minikube node in the `Ready` state.

## **3. How Minikube works with Docker**

This is the important part.

Docker and Minikube have different responsibilities.

| Tool           | Responsibility                                           |
| -------------- | -------------------------------------------------------- |
| Docker Desktop | Provides the Docker environment on your Windows machine. |
| Minikube       | Creates and runs the local Kubernetes cluster.           |
| Kubernetes     | Manages application containers inside the cluster.       |
| kubectl        | Sends commands to the Kubernetes API Server.             |

### **Architecture / Working Flow**

```
          Windows Machine
                |
          Docker Desktop
                |
                v
         Minikube Node
       (Docker Container)
                |
         Kubernetes Cluster
                |
          Worker Node
                |
              Pods
                |
        Spring Boot Container
```

**How it works:**

1. Docker Desktop starts its Docker Engine.
2. Minikube uses Docker as its driver to create a container representing the Kubernetes Node.
3. Minikube sets up Kubernetes components inside that Node.
4. You use `kubectl` to communicate with the Kubernetes API Server.
5. Kubernetes schedules Pods and runs application containers using the Node's container runtime.

Note: Minikube commonly uses containerd as its internal container runtime by default. Docker is the driver here, not necessarily the runtime used for application containers.&#x20;

## **4. Run a sample application**

Let's deploy an Nginx application to understand how it works.

**Step 1: Create Deployment**

```
kubectl create deployment my-app --image=nginx
```

**Step 2: Check Pods**

```
kubectl get pods
```

**Step 3: Expose the application**

```
kubectl expose deployment my-app --type=NodePort --port=80
```

**Step 4: Access the application**

```
minikube service my-app
```

This opens the application in your browser.

**Step 5: Clean up**

```
kubectl delete service my-app
kubectl delete deployment my-app
```

## **5. How to deploy your own Spring Boot Docker image?**

Suppose you have a Spring Boot application and a Dockerfile.

Build the Docker image:

```
docker build -t springboot-app:v1 .
```

Load the image into Minikube:

```
minikube image load springboot-app:v1
```

Create a Deployment YAML:

```
apiVersion: apps/v1
kind: Deployment
metadata:
  name: springboot-app
spec:
  replicas: 1
  selector:
    matchLabels:
      app: springboot-app
  template:
    metadata:
      labels:
        app: springboot-app
    spec:
      containers:
        - name: springboot
          image: springboot-app:v1
          imagePullPolicy: IfNotPresent
          ports:
            - containerPort: 8080
```

Apply it:

```
kubectl apply -f deployment.yaml
```

Check:

```
kubectl get pods
```

`minikube image load` makes your locally built image available to the cluster without pushing it to Docker Hub.&#x20;

## **6. Useful Minikube Commands**

| Command                     | Purpose                        |
| --------------------------- | ------------------------------ |
| `minikube start`            | Start cluster.                 |
| `minikube stop`             | Stop cluster.                  |
| `minikube status`           | Check cluster status.          |
| `minikube delete`           | Delete cluster.                |
| `minikube dashboard`        | Open Kubernetes Dashboard.     |
| `minikube ip`               | Get cluster Node IP.           |
| `minikube service my-app`   | Access an application Service. |
| `minikube image load IMAGE` | Load local image into cluster. |

## **Remember for interviews**

- Docker → Builds container images.
- Minikube → Runs a local Kubernetes cluster.
- Kubernetes → Manages application containers.
- kubectl → Communicates with Kubernetes.
- Docker driver → Uses Docker to create the Minikube Node.
