## **1. ConfigMap in Kubernetes**

**What is it?**

ConfigMap stores non-sensitive application configuration separately from application code and container images.

### **Why do we need it?**

- Avoid hardcoding configuration inside application code.
- Maintain different configurations for development, testing, and production.
- Update configuration without rebuilding the Docker image.

### **What does it contain?**

Non-sensitive configuration data, such as:

- Database URL
- Application environment
- API endpoints
- Application properties
- Feature flags

**Example:**

```
apiVersion: v1
kind: ConfigMap
metadata:
  name: app-config
data:
  DB_URL: jdbc:mysql://localhost:3306/mydb
  APP_ENV: production
```

## **2. Secret in Kubernetes**

**What is it?**

Secret stores sensitive information separately from application code and container images.

### **Why do we need it?**

- Avoid hardcoding sensitive information.
- Manage credentials separately from application code.
- Provide sensitive values to containers when required.

### **What does it contain?**

Sensitive information, such as:

- Database username and password
- API keys
- Authentication tokens
- TLS certificates
- Private keys

**Example:**

```
apiVersion: v1
kind: Secret
metadata:
  name: db-secret
type: Opaque
data:
  DB_USERNAME: YWRtaW4=
  DB_PASSWORD: YWRtaW4xMjM=
```

Note: Secret values under `data` must be Base64 encoded. Base64 is encoding, not encryption. Use encryption at rest and appropriate access controls to protect Secrets.

## **3. ConfigMap vs Secret**

| ConfigMap                                 | Secret                                            |
| ----------------------------------------- | ------------------------------------------------- |
| Stores non-sensitive data.                | Stores sensitive data.                            |
| Database URL, environment, API endpoints. | Passwords, tokens, API keys.                      |
| Values are stored as plain text.          | Values are commonly Base64 encoded.               |
| Used for application configuration.       | Used for credentials and sensitive configuration. |

**In simple words:**

- ConfigMap → Stores application configuration.
- Secret → Stores sensitive information.

**Real-world example:**

For a Spring Boot application:

- ConfigMap → Database URL and application environment.
- Secret → Database username and password.
