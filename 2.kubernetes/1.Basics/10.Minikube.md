## **Minikube in Kubernetes**

**What is Minikube?**

Minikube is a tool that runs a local Kubernetes cluster on your computer, mainly for learning, development, and testing.

### **Why do we need it?**

- Run Kubernetes locally without a cloud cluster.
- Learn and practice Kubernetes concepts.
- Test Kubernetes YAML configuration files.
- Deploy and test applications locally.
- Avoid the cost of cloud Kubernetes services during development.

### **How does it work?**

Minikube creates a local Kubernetes cluster, typically with a single Node, on your machine.

### **Example**

Suppose you have a Spring Boot application:

1. Create a Docker image.
2. Start Minikube.
3. Deploy your application using `deployment.yaml`.
4. Expose it using a Kubernetes Service.
5. Test your application locally.

### **Important Commands**

```
# Start Minikube
minikube start

# Check cluster status
minikube status

# View nodes
kubectl get nodes

# Stop Minikube
minikube stop

# Delete cluster
minikube delete
```

### **Minikube vs Kubernetes**

| Kubernetes                          | Minikube                                         |
| ----------------------------------- | ------------------------------------------------ |
| Container orchestration platform.   | Tool to run Kubernetes locally.                  |
| Used in production and development. | Mainly used for local development and learning.  |
| Can manage large clusters.          | Typically runs a single-node cluster by default. |

**In simple words:** Minikube allows developers to practice and test Kubernetes on their local machines without needing a cloud-based Kubernetes cluster.

**No. Minikube is generally NOT used in production.**

Minikube is primarily designed for **local development and learning Kubernetes**.

### **Where do we use Minikube vs Kubernetes?**

| Environment       | Kubernetes platform                | Purpose                   |
| ----------------- | ---------------------------------- | ------------------------- |
| Local development | Minikube                           | Learning and testing      |
| Development       | Minikube / Kind / K3s / Cloud K8s  | Application development   |
| Testing / Staging | Managed Kubernetes                 | Integration and testing   |
| Production        | EKS / AKS / GKE / Self-managed K8s | Running real applications |

### **What is used in production?**

Common production Kubernetes platforms:

1. **AWS EKS** – Amazon Elastic Kubernetes Service.
2. **Azure AKS** – Azure Kubernetes Service.
3. **Google GKE** – Google Kubernetes Engine.
4. **Self-managed Kubernetes** – Kubernetes clusters managed by the organization.

**Interview answer:**

Minikube is a lightweight Kubernetes implementation mainly used for local development, learning, and testing. In production, organizations generally use managed Kubernetes services like AWS EKS, Azure AKS, or Google GKE, which provide production-grade cluster management and scalability.
