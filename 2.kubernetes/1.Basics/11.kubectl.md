## **kubectl in Kubernetes**

### **1. What is kubectl?**

**kubectl** (Kubernetes Control) is a command-line tool used to communicate with and manage a Kubernetes cluster.

### **2. Why do we need it?**

- Create and deploy Kubernetes resources.
- View Pods, Nodes, Services, and Deployments.
- Scale applications.
- Update and delete resources.
- Troubleshoot application issues.

### **3. How does it work?**

`kubectl` sends requests to the Kubernetes API Server, which processes them and updates the cluster state.

### **4. Where can we use it?**

We can use `kubectl` from:

- Local terminal (Windows, Linux, macOS).
- VS Code terminal.
- Cloud shell (AWS, Azure, GCP).
- GitHub Codespaces terminal.

It can manage local clusters (Minikube) and remote Kubernetes clusters.

### **5. Important Commands**

| Command                                     | Purpose                             |
| ------------------------------------------- | ----------------------------------- |
| `kubectl get nodes`                         | List cluster nodes.                 |
| `kubectl get pods`                          | List Pods.                          |
| `kubectl get deployments`                   | List Deployments.                   |
| `kubectl get services`                      | List Services.                      |
| `kubectl apply -f file.yaml`                | Create or update resources.         |
| `kubectl delete -f file.yaml`               | Delete resources defined in a file. |
| `kubectl describe pod pod-name`             | Get detailed Pod information.       |
| `kubectl logs pod-name`                     | View container logs.                |
| `kubectl scale deployment app --replicas=3` | Scale application to 3 replicas.    |

**In simple words:** kubectl is the command-line interface used to interact with and manage Kubernetes clusters.

**Remember:**

- Kubernetes → Manages containers.
- Minikube → Runs Kubernetes locally.
- kubectl → Communicates with and manages Kubernetes.
