## **What is Ingress in Kubernetes?**

**Ingress** is a Kubernetes resource that manages external HTTP and HTTPS access to applications running inside a Kubernetes cluster.

It acts as an entry point and routes incoming requests to different Services based on hostname or URL path.

### **Why do we need Ingress?**

- Provides a single entry point for multiple applications.
- Routes requests based on URL paths or domain names.
- Supports HTTPS using SSL/TLS.
- Avoids exposing every application through a separate NodePort or LoadBalancer.

### **Example**

Suppose you have two applications:

- React Frontend Service
- Spring Boot Backend Service

Ingress can route requests as follows:

```
External Users
      |
      v
   Ingress
      |
      |---- /          --> React Service
      |
      |---- /api       --> Spring Boot Service
```

### **Important Components**

| Component          | Purpose                                                |
| ------------------ | ------------------------------------------------------ |
| Ingress            | Defines routing rules for external HTTP/HTTPS traffic. |
| Ingress Controller | Implements those rules and handles incoming traffic.   |

Examples of Ingress Controllers:

- NGINX Ingress Controller
- Traefik
- HAProxy

**Important:** Creating an Ingress resource alone is not enough. An Ingress Controller must be installed to process its rules.

### **Ingress vs Service**

| Service                             | Ingress                                         |
| ----------------------------------- | ----------------------------------------------- |
| Provides network access to Pods.    | Routes external HTTP/HTTPS traffic to Services. |
| Supports different service types.   | Supports hostname and URL path-based routing.   |
| Works at the network/service level. | Works mainly at the HTTP/HTTPS level.           |

**In simple words:** Service provides access to Pods, whereas Ingress manages how external HTTP/HTTPS requests reach different Services.
